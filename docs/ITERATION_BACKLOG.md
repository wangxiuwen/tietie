# tietie 持续迭代方向池

> 定时迭代任务的工作协议：**每轮只做一个方向**。从下方第一个未完成项开始，
> 走完整流程（实现 → fmt/clippy/tsc 门禁 → 构建 → 静默重装 → 真机冒烟验证 →
> commit + push），然后把该项勾掉并附完成日期与 commit 短 SHA。
> 若未完成项少于 3 个，先按产品定位（跨平台复制粘贴便利贴：内容随手存、
> 随手取、快捷键可自定义）追加新方向再继续。
> 禁止一轮做多件事；门禁不绿不许 commit；每轮必推送。
